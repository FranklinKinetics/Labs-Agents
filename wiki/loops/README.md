# Loops

Every recurring workflow the crew runs, one page each. A loop that isn't written here doesn't run. When a loop is added or changed, Ines updates its page and logs the change in the weekly review.

Each page states: **trigger · owner · model · steps · output · Brandon's minutes.**

| Loop | Trigger | Owner | Brandon's minutes |
|---|---|---|---|
| [Weekly review](weekly-review.md) | Every Sunday | Ines (Haiku) | 10 / week |
| [Brandon's queue](brandon-queue.md) | Anything needs G1, G2 or a Vera flag | Ines | ≤ 45 / week |
| [Discovery outreach](discovery-outreach.md) | Active discovery test | Ines, Fenn, Vera | ~110 / week while sending |
| [Lab release](lab-release.md) | A Lab build is ready, or a live page changes | Fenn, Vera | one G1 packet |
| [Signal tracking](signal-tracking.md) | Every Sunday, before the weekly review | Ines (Haiku) | 1 (one number) |
