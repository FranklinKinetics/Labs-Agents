# Franklin Kinetics brand

## Labs design system (use this for every Lab PDF, product image and download)
Matched on 2026-11-28 to the Lab 01 and Lab 02 product art (`lab-01-automatic-groceries.png`, `lab-02-regina-data-map.png`, from the live store). **Brandon's rule: Lab outputs must look like these.** Working template: `labs/truck-note-to-invoice/squarespace/make-pdf.js`.

| Element | Spec |
|---|---|
| Canvas | Dark teal `#2B424A`, full bleed |
| Grid | Thin rules `#455A61`: two vertical lines inset from the edges, and horizontal dividers between bands |
| Top band | White horizontal logo with the spark (`logo-secondary-white.webp`) on the left; `LAB / 0N` on the right, in mono, grey `#85959A` |
| Title | **Outfit** 700, burnt orange `#ED6B2E`, very large, tight, sentence case, two lines (a close match to the art; confirm the exact face from the designer's kit) |
| Tagline | **DM Mono**, UPPERCASE, wide tracking (about 0.2em), beige `#EDE8E0` |
| Badge | A circular ring of mono text with the orange spark in the centre, top right of the title band |
| Card | Beige `#EDE8E0` panel; Outfit heading in teal; dashed rule; rows with small orange squares; mono "pill" tags (filled orange, or outlined teal) |
| Tiles | A row of 5 blocks in `#1F333A`, `#ED6B2E`, `#F0895A`, `#55676D`, `#ED6B2E`, each with a mono label and short text |
| Footer band | `FRANKLINKINETICS.COM` in grey mono on the left; one orange mono line on the right (e.g. `FREE · WORKS OFFLINE`, `WORKS WITH CLAUDE`) |
| Body text | Inter (or Helvetica/Arial) |

Lab numbers: 01 Automatic Groceries · 02 Regina Data Map · 03 Truck Note to Invoice.

## Website (franklinkinetics.com)

Read from the live site on 2026-11-27 by rendering it with its own stylesheets. **The master is the designer's kit** ("Franklin Kinetics Visual Identity Assets.zip", Klay Design, in Brandon's Drive). If the kit's guide differs from this, the kit wins.

Used by: `labs/truck-note-to-invoice/squarespace/make-pdf.js` (a working template for branded PDFs).

| Element | Value |
|---|---|
| Headings | **Syne**, bold (700–800), UPPERCASE, tight letter-spacing (about −0.03em) |
| Body and buttons | **Titillium Web** (the site also loads Clarkson, an Adobe Fonts face; not used in PDFs, for licensing) |
| Ink (body text) | `#2B424A` (dark teal) |
| Paper (page background) | `#ECE7DF` (warm beige) |
| Hero bands | `#000000` with white text, and a curved lower edge |
| Accent (buttons, eyebrows, numbers) | `#ED6B2E` (burnt orange); buttons are square-cornered, with white text |

Logos (WebP, from the site): `logo-primary.webp` (full colour, for light backgrounds), `logo-wordmark-white.webp` and `logo-secondary-white.webp` (for black bands).
