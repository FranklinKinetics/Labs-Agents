# Wave 1, short version (for diagnostic graduates)

> **Beta only.** This file belongs to the Rotor Beta and to diagnostic graduates who go into it. The Rotor Distillation does not use it: it uses `wave-fit.md` and `wave-ceo.md`. Kept as it was.

For Brandon. This replaces the standard wave 1 file in the Interviewer Pack for a company whose leaders took the alignment diagnostic first and agreed to share it. The Interviewer Pack itself is unchanged: the same core instructions, the same summary block, the same disclosure note (with the program line added at RP3). Only the wave file changes.

**Wave 0 is the leader's diagnostic result.** The diagnostic asks the same questions as standard wave 1, so each leader has already answered most of them. The short version asks only what is still missing, so each session runs about 10 to 12 minutes instead of 20.

## How you fill it in

Before you attach the file, read each leader's wave 0 answers and fill in the "Already answered" line for that leader, using the question numbers from the standard wave 1 list below.

Mark a question as answered only when the diagnostic answer is specific enough to use: a real decision, a real example, a clear sentence. If it is vague, leave the question off the answered list so it gets asked again. When in doubt, ask. The leader can always say "I covered that already" and skip it.

Where a leader has no wave 0 data, delete their section and give them the standard wave 1 file instead. The interviewer will follow the notes by name; for a leader not listed, it asks the general questions in full.

## Questions the short version keeps

These are always asked, whatever wave 0 said:

- **K1** confirms the main effort is still true, since time has passed since the diagnostic.
- **Q8**, the image or story of the company at its best (language harvest needs fresh words).
- **Q10**, the outside-work question (it feeds the examples chosen later).

These are asked only if you have not marked them answered for that leader: Q1, Q2, Q3, Q4, Q5, Q6, Q7, Q9. Q1, Q2, Q3 and Q6 stay marked ESSENTIAL when they are asked.

The file to attach is the block below. Copy it, fill in the leader sections, and delete this header.

```markdown
# Wave 1 questions (short version)
This is a short session of about 10 to 12 minutes. The person has already answered some questions in an earlier diagnostic. Do not mention what they said there and do not read anything back from it. Open by saying you will only ask about what is still missing.

Ask in this order. ESSENTIAL questions first if time is short. For a named leader, skip the questions listed under "Already answered" in their section. For anyone not named, ask the general questions in full.

## <Leader name>, <role>
Already answered (skip these): [Q numbers, for example Q1, Q3, Q4]
Always ask K1, Q8 and Q10, then every other question below that is not skipped.

## General questions (anyone not named above)
Ask all questions below, in order.

## Questions

K1. ESSENTIAL: Since you last thought about it, has anything changed in how you would put the company's main effort this year? Say it in one sentence.

Q1. ESSENTIAL: In one sentence, where is this company putting its main effort this year, and why?
Q2. ESSENTIAL: What are we deliberately giving up or saying no to, to make that happen?
Q3. ESSENTIAL: When two good things collide, such as a big new client versus serving existing ones, which way should people lean?
Q4. What do we believe about our market, customers or people that, if wrong, would change the plan?
Q5. What would tell you early that one of those beliefs is failing?
Q6. ESSENTIAL: What slows this company down most? Where does work wait?
Q7. What did we decide in the past year that didn't stick? Why not?
Q8. When this company is at its best, what is it like? What image or story captures it?
Q9. Where did our money and people actually go last year? Does that match the main effort you described?
Q10. Outside work, what do you know well (a sport, a craft, an instrument, a field)? Ask this last and keep it light; it helps choose examples later.
```

## Check before the first use

- [ ] A leader with Q1 to Q7 marked answered gets only K1, Q8, Q9 and Q10, and the session stays short.
- [ ] The interviewer never repeats back or refers to the leader's diagnostic answers.
- [ ] A leader with nothing marked answered gets the full list and nothing is missing.
- [ ] The summary block still comes out in the exact standard format, with "none" in any field the person was not asked about.
