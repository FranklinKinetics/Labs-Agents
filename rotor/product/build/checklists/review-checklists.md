# Brandon's review checklists

One checklist for each judgment touchpoint in the spec (T4, T5, T6, T9). Each fits on a phone screen. Tick through it, then log the step in the override log: changed or not, and why. Times are budgets from spec section 4.

---

## T4 · Reading a transcript (~10 min each)
*Run after each leader's session, before A2's synthesis enters anything.*

- [ ] The summary block matches the transcript. No quote appears in the block that the leader didn't say.
- [ ] The interviewer asked one question at a time, followed up on vague answers, and gave no advice.
- [ ] Anything the leader asked to leave out is left out.
- [ ] Note in one line: the thing this leader sees that the others might not.
- [ ] Note any image, metaphor or saying worth keeping for the language map.
- [ ] Anything confidential (acquisitions, people decisions, legal matters, unannounced financials) is flagged for exclusion.
- [ ] If the interviewer misbehaved, log it against S1 and note the fix to its instructions.

## T5 · Synthesis, wave 2 file and divergence summary (~95 min per company)
*A2 synthesis after each wave, the A3 wave 2 file and the A4 divergence summary.*

**Synthesis (A2)**
- [ ] Every theme traces back to at least one summary block. No theme is invented.
- [ ] Agreements and differences are both shown, and the differences are not smoothed over.
- [ ] Quotes are unattributed and are leaders' exact words.

**Wave 2 file (A3)**
- [ ] Each leader's follow-ups build on their own wave 1 answers.
- [ ] The probe on where a view differs is neutral, and names no one.
- [ ] Each leader has no more than four questions, with the essentials marked.

**Divergence summary (A4)**
- [ ] Two pages or less.
- [ ] Nobody is identifiable, even by role, where the team is small.
- [ ] It ends with the questions the Mirror must settle.
- [ ] The language harvest lists the 2–3 candidate metaphors and the exact words behind them.

## T6 · Choosing the schwerpunkt candidates (~105 min per company)
*The judgment clients pay for. Never handed to AI.*

1. [ ] **Before opening A5's draft** (first two intakes): write your own one-line view in the company's project. The override log records only whether it matched (yes / partly / no).
2. [ ] Read A5's 3–5 options. For each, ask: "If this were the main effort, what would they stop doing next month?" Cut any option with no clear answer.
3. [ ] Keep 2–3 candidates for wave 3, each one sentence long, each with its trade-off named. Rewrite them in the company's words.
4. [ ] Guardrails: 5–7, each in "when X conflicts with Y, favour X" form where possible, with one good call and one bad call from the leaders' own examples.
5. [ ] Living models: 8–12, each with a tripwire. Mark the ones you think are load-bearing.
6. [ ] Run A6 (the five-tests checker) on the lot. Fix or cut every line that fails.
7. [ ] Write the wave 3 file. Its draft is a starting point, not a decision, and it should say so.
8. [ ] Log the step as S5. It is logged for learning only.

## T9 · Sheet, video script and red-team (~120 min per company)
*After the Mirror.*

**The Rotor Sheet**
- [ ] It matches what the room decided at the Mirror, word for word where the room chose words.
- [ ] Every line passes A6's five tests.
- [ ] The language map uses the metaphor the room chose.
- [ ] The owner and the first review date are filled in.
- [ ] Exclusions are respected.

**The video script (A7)**
- [ ] Choices, not slogans.
- [ ] Every guardrail has an example.
- [ ] 2–3 minutes when read aloud at the CEO's pace.
- [ ] It's in the company's language.

**Red-team (A8)**
- [ ] Each dilemma is classed as ambient, nudge or explicit, and you agree with the class.
- [ ] Nudges are questions, not corrections.
- [ ] Informed overrides are accepted without argument.
- [ ] There are no wrong calls on the explicit cases.
- [ ] After tuning, re-run the failures. Go live only when the target in the playbook (Async step: Red-team) is met.
